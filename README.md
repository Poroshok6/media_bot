# Бот заявок на дизайн для медиа ВУЗа

## Запуск за 15 минут

### 1. Установи Python
Скачай его с python.org (версия 3.10 или новее). При установке на Windows **обязательно поставь галочку «Add Python to PATH»**.

### 2. Создай бота в Telegram
1. Найди в Telegram **@BotFather** и напиши ему `/newbot`.
2. Придумай имя (например, «Медиа СИУ — заявки») и username, который заканчивается на `bot`.
3. BotFather пришлёт **токен**, длинную строку вида `123456:ABC-...`. Никому его не показывай.

### 3. Настрой проект
1. Распакуй архив в любую папку.
2. Создай файл `.env` из образца. В терминале, открытом в папке бота (см. пункт 3):
   ```
   copy .env.example .env
   notepad .env
   ```
   Вставь токен вместо текста-заглушки: без пробелов вокруг `=` и без кавычек. Сохрани файл (Ctrl+S).
   Проверь командой `dir /a`: файл должен называться именно `.env`, а не `.env.txt`.
   Если получился `.env.txt`, переименуй: `ren .env.txt .env`.
3. Открой терминал в этой папке (в Windows: в адресной строке проводника набери `cmd` и нажми Enter) и выполни:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
   Появится надпись «Бот запущен!».

### 4. Укажи, куда приходят заявки
1. Напиши своему боту `/id`, и он пришлёт ID чата.
   - Чтобы заявки приходили в общий чат медиа, добавь бота в группу и напиши `/id` уже там. ID группы начинается с минуса.
2. Вставь этот номер в `.env` в строку `ADMIN_CHAT_ID=`.
3. Перезапусти бота: нажми Ctrl+C, затем снова `python bot.py`.

### 5. Проверь
Нажми «📝 Новая заявка», пройди все шаги и отправь заявку. В админ-чате появится карточка с кнопкой «Взять в работу».

## Важно
- Бот работает, пока на компьютере открыт терминал. Чтобы он работал круглосуточно, его потом переносят на сервер (VPS). Это следующий шаг.
- Все заявки сохраняются в файле `requests.db`.
